How to Use SLI

A practical guide to navigating Indonesia's strategic economy—from an executive big picture to verifiable provincial, sectoral and project evidence.

Principle: Overview tells you what matters. Detailed dashboards show the underlying evidence. Glossary & Methodology explain what each number means, how it was obtained and what it cannot prove.

01 · Start with Overview, then investigate

For a quick decision brief

  1. Open Overview for a selective national summary.
  2. Identify the relevant sector, location, or emerging development.
  3. Open its specialized dashboard to inspect the measured value, source, time period, caveat and interpretation.
  4. Use the Glossary & Methodology before making comparisons.

For an investor or analyst

  1. Select an investment sector through Investment Tracker.
  2. Compare candidate regions with Provincial Opportunity & Stress.
  3. Inspect a specific location in Provincial Investment Dossiers and corroborate spatial assets using Strategic Map.
  4. Open original sources; treat scenario outputs as conditional, not bankable project returns.

Overview is intentionally selective, not an exhaustive duplicate of every sector dataset. Use the related links and grouped module menu on each page to reach deeper evidence.

04 · Search, filter, chart, map and export

Search / Pencarian

Use the top search on the main SLI page (shortcut Ctrl + K). Try a precise asset or province such as SPKLU Jawa Barat, Rokan, Gini Jawa Barat. Select “All dashboards” to search across the public index. A selected result leads to its source-linked module, and some datasets have exact province links.

Some source records are indexed only to their owning section, not a dedicated row panel. When this happens, the result should show its title, description and indexed source so you can identify what matched. Search is not a real-time global web search.

Charts, scatterplots and regional comparisons

Read axis labels, units, vintage and population before comparing. For province plots, change one variable at a time. A correlation is descriptive and does not establish a causal impact or an investment return. “N/A” identifies unavailable data, not zero.

Spatial maps and provincial pins

Filter by sector, project stage, geography and available layers. Exact site coordinates, address geocodes and province centroids have different precision. Where a record is only provincial, the map must not imply that the marker is the surveyed facility location. One asset may occur in several source registries; avoid summing overlapping counts.

Downloads and export

Where a dashboard provides CSV or copy controls, apply your filters first and then export. CSV is a working research extract, not a certified source table. Preserve accompanying dates, units, scope, links, notes and missing-value policies. Features vary by module: absence of an export button does not imply source data are inaccessible.

English and Bahasa Indonesia

The main overview and shared glossary provide EN/ID controls. Some specialist source tables retain original terminology. Switching language changes the display, not a source document, value or observation period.

CheckMeaningWhy it matters
1. Publisher / SourceBPS, PLN, ESDM, BI, BKPM, company report or editorial leadDifferent evidence grades and original publication rights
2. Observation periodThe year/month the phenomenon was measured2024 observations do not become 2026 measurements after a dashboard refresh
3. Release and last checkedPublisher release date vs SLI validation/refreshA successful workflow does not certify that the underlying source changed
4. Unit / denominatorMW, MWh, GWh, USD, IDR, households, villages, people, capacityUnlike quantities cannot be added, compared or converted without assumptions
5. Status / scopeAnnounced, financed, building, commissioned, operating; source coveragePipeline figures and real expenditures are not interchangeable
6. Model vs observationMeasured, estimated, scenario, forecast or unverified reportAssumptions, uncertainty and causal limitations govern interpretation

Review Data Freshness & QA for the published monitoring coverage. Not every data series has a fully automatic primary-source refresh; if a feed fails, dated data should remain dated instead of being silently presented as new.

06 · Analytical methods: what the outputs can and cannot say

Provincial score & comparison

An adjustable within-sample indicator composition, not an audited investment grade, project NPV, risk premium or financial advice. Rankings depend on chosen weights and the set of provinces included.

Growth × Gini & panel analysis

Descriptive cross-sections and panel associations. Gini measures expenditure inequality, which must not be read as measured income inequality. Correlations alone cannot establish causal mechanisms.

Input–output multiplier

Gross output responses need a verified, relevant transactions matrix and sector definition. A user-supplied coefficient and source link do not validate a local multiplier; gross output is not an automatic addition to provincial GRDP or jobs.

Scenario/stress lab

Outputs change with user assumptions; scenarios are not forecasts or probabilities unless explicitly estimated and validated with suitable historical data.

Full methods, assumptions and technical vocabulary: Glossary & Methodology · Sector methods. National data use official series and source-specific caveats.

07 · Problems, common questions and support

I clicked search but it opened a section rather than the exact row

Many raw source registries currently lack dedicated record-level detail panes. The selected search item includes a focused description and source link when available; compare it against the section contents. An exact province page is available for Gini and provincial investment profiles.

The dashboard shows an empty chart or missing data

Check the year, province and filters, then the module's available coverage and source freshness. An absent value is “N/A”, not zero. If a source file fails, the corresponding component may remain unavailable instead of displaying guessed numbers.

A feature looks unchanged after an update

Reload the page; in desktop browsers, Ctrl + Shift + R can bypass older cached JavaScript. Compare the published dataset vintage rather than assuming the latest source release is reflected. Review the automation status.

Can I use a result in a commercial investment report?

Check the primary publisher's reuse rights, attribution requirements and original source. SLI interpretations are general research, not individualized legal, financial, engineering, securities or investment advice. Confidential/private information is excluded from public research.

For corrections, record the module name, search keyword, result selected, expected content and original-source URL, if available. You can contact SLI via the public research inquiry link on About SLI.
