Uji simpan watchlist (opsional)

Uji berikut menggunakan akun yang sedang login. Ticker contoh ditambahkan tanpa menghapus preferensi yang sudah ada. Klik tombol simpan hanya jika Bos mengizinkan perubahan data akun.

Belum ada uji tulis. Tidak ada perubahan akun yang dilakukan halaman ini secara otomatis.

Catatan: Jika akun sebelumnya belum terdaftar (enrolled: false), penyimpanan pertama akan mendaftarkan akun. Halaman ini tidak menghapus akun secara otomatis untuk kembali ke keadaan tersebut. Jika akun sudah terdaftar, tombol pulihkan mengembalikan preferensi sebelumnya dengan pemeriksaan konflik.

Keamanan: Halaman uji ini tidak menyimpan cookie/token, tidak menampilkan email atau isi inbox, dan hanya menulis preferensi setelah konfirmasi. Snapshot pemulihan disimpan di memori tab selama sesi, bukan pada server atau localStorage. Jika login di Worker berhasil tetapi pengujian dari sini gagal, mungkin ada hambatan cookie lintas situs. Dashboard utama tetap nonaktif sampai QA selesai.
